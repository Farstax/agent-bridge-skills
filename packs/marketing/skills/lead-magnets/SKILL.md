# Lead Magnets

## Job

Design a free asset specific enough to be genuinely useful in minutes, that
creates a natural next step toward the paid offer.

## Trigger

Use once positioning and offer exist, when building a conversion funnel or
opt-in page.

## Required inputs

- The positioning statement and offer.
- The single narrowest problem this asset should solve (not "marketing help"
  — "the exact subject line to use for a cart-abandonment email").

## Method

1. Pick a format that matches the promise: a checklist or template for a
   fast, concrete win; a calculator for a numeric decision; a short
   walkthrough for a process. Match format to speed-to-value, don't default
   to a long document.
2. Validate the idea against: does it solve a specific problem in a few
   minutes; is the promise distinct from a vague competitor claim; does using
   it naturally raise the need the core offer solves.
3. Draft the landing page structure: a specific headline (promise + how, not
   a claim without a mechanism), a short explanation of the mechanism, a
   handful of concrete benefits, and a direct call to action.

## Evidence requirements

The problem the asset solves must trace to a real pain point (from
`market-research` or existing customer knowledge). Don't invent a problem to
justify an asset format.

## Outputs

An asset brief: title, format, the specific problem it solves, structure, and
how it connects to the core offer's next step.

## Failure / insufficient evidence

If no clear, narrow problem is available, ask for one instead of designing a
generic asset.

## Dependencies and effects

No external service required. This Skill produces a brief and, if asked,
draft copy — it does not publish the asset or collect any opt-in data itself.
