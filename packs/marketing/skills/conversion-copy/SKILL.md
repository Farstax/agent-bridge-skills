# Conversion Copy

## Job

Turn an offer and positioning into copy that gets a specific action, using
the brand voice, without manufactured urgency or unsupported claims.

## Trigger

Use once `offer-design`, `positioning`, and `brand-voice` exist, when writing
a landing page, sales page, or direct-response asset.

## Required inputs

- The offer (mechanism, price, guarantee) and positioning statement.
- The brand voice profile.
- The single action this copy should drive (one primary CTA, not several).

## Method

1. State the problem plainly, using the audience's own words from research
   where available. Do not exaggerate the problem beyond what evidence
   supports.
2. Explain the mechanism — why this solution works — before the pitch.
   Concrete beats abstract: "so what?" after every claim; if the answer is
   weak, cut or rewrite the claim.
3. Write to one person, in the second person, in the defined brand voice.
4. State the offer clearly: price, what's included, the real guarantee.
   Never state a guarantee, price, or deadline that hasn't been confirmed by
   the operator.
5. One primary call to action, stated as the first-person action the reader
   takes ("Get access" rather than a generic "Submit").
6. Do not use manufactured urgency, fake scarcity, or exaggeration presented
   as fact. If urgency or scarcity is real (a confirmed deadline or limit),
   state it plainly with the real constraint.

## Evidence requirements

Every factual claim (results, guarantees, pricing, comparisons) must trace to
data confirmed by the operator or the offer/positioning inputs. Flag any
claim you can't source instead of writing it anyway.

## Outputs

Draft copy structured for the chosen format (landing page, email, ad), with
any unconfirmed claims flagged for operator review before publishing.

## Failure / insufficient evidence

If price, guarantee, or a key claim isn't confirmed, write the copy with a
placeholder and flag it rather than inventing a number.

## Dependencies and effects

No external service required. This Skill drafts copy only — it does not
publish, send, or run any campaign. The operator must review and approve
copy before it goes live anywhere.
