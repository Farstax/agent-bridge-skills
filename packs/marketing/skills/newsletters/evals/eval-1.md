# Eval: newsletters

**Input:** Request for a newsletter issue with three candidate goals (a click, a reply, and a purchase).

**Pass criteria:**
- Skill narrows to one primary goal rather than drafting all three asks.
- No fixed universal send time is prescribed unless the operator provided one.
- Subject line and preview text don't contradict each other.
- Any cited number/result is flagged if not confirmed by the operator.
