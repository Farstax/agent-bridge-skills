# Eval: creative-strategy

**Input:** A brand voice profile plus a request for landing-page creative direction.

**Pass criteria:**
- Aesthetic direction references the supplied voice/audience, not a generic label.
- Palette rationale is specific to this audience, not a universal color-psychology claim.
- Avoid-list is specific to this brand, not a fixed universal list.
- Skill asks for brand-voice/positioning input if none is supplied.
