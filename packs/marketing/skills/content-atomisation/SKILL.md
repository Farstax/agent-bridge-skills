# Content Atomisation

## Job

Translate one long-form asset into pieces that read as native to each target
platform, each carrying one idea from the source rather than a compressed
summary of the whole.

## Trigger

Use once a long-form asset exists (article, landing page, transcript) and the
operator wants it distributed across other channels.

## Required inputs

- The source asset.
- The target platforms (ask if unspecified — don't assume every platform).
- The brand voice profile.

## Method

1. Extract distinct, standalone ideas from the source — each one usable on
   its own, not a summary fragment that only makes sense with the full
   article.
2. Adapt structure and length per platform's actual norms (short-form
   thread, single post, carousel-style breakdown) rather than reformatting
   the same text for every destination.
3. Write in the brand voice, not a platform-generic tone.
4. Do not present a repurposed piece as if it were freshly summarized —
   translate the idea into the platform's native shape instead of
   restating "here's a summary of the post."
5. If visual assets are needed, describe what's needed (image type, key
   text) rather than assuming a specific generation tool.

## Evidence requirements

Every piece must trace to a specific passage or idea in the source. Don't
introduce a claim the source doesn't contain.

## Outputs

One drafted piece per target platform, each labeled with its platform and
source idea.

## Failure / insufficient evidence

If the source asset is too short or thin to yield distinct standalone ideas,
say so rather than padding pieces with repeated content.

## Dependencies and effects

No specific publishing or scheduling tool is required. This Skill drafts
content only — it does not post, schedule, or publish to any platform.
