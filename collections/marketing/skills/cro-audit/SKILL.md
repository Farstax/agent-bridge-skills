# cro-audit

Provider-neutral adaptation of Corey Haines's Marketing Skills (`skills/cro/SKILL.md`, MIT). Use current repository instructions and tools already available in the agent session; never require upstream product-marketing files or uninstalled companion skills.

Diagnose marketing-page conversion friction, then propose testable changes. Diagnosis is not a promise of lift.

## Work
1. Identify page type, intended audience, channel/message match, primary conversion, journey beyond the CTA and available page/analytics access.
2. Inspect source or rendered page and any authorised analytics or funnel evidence. Mark each finding **observed**, **reported**, or **hypothesis**. If no live page/analytics is accessible, state the missing evidence.
3. Review value-proposition comprehension, headline, CTA visibility and hierarchy, message consistency, credibility/trust claims, objection handling, form fields, errors, mobile usability, speed and continuity through signup/payment.
4. Prioritise by likely impact, confidence **based on evidence**, implementation effort and testing cost. Distinguish obvious defects from uncertain marketing hypotheses.
5. Produce a concise audit: evidence and location, expected user friction, priority, low-risk correction or proposed experiment, necessary measurement, and limitations. Never manufacture visitors, conversion rates or lift estimates.

## Boundaries
`conversion-copy` creates copy; `impeccable` audits UI implementation and accessibility; `ab-testing` designs experiments. This skill diagnoses conversion journeys only. No unrequested site edits, account mutations or external publishing.

## Output integrity
Clearly separate evidence, assumptions and recommendations. Ask only for material missing information that cannot be found in available context. Never represent a hypothetical model as real campaign or customer data.
