# Deep Research

## Job and trigger
Use for substantial, multi-source investigation or a formal cited report. For specific audience complaints use the existing market-research Skill instead. For a narrow factual question, answer directly; do not launch a research workflow.

## Research contract
Define the question, reader, geographic and temporal scope, intended decision and the expected output. Check which search, page retrieval or file tools the selected provider actually exposes. This Skill grants no internet or MCP access.

## Method
1. Break the question into a small number of answerable subquestions; test plausible opposing viewpoints where material. This is a working plan, not a separate durable queue, agent controller or background loop.
2. Gather primary evidence first: papers, official documentation, filings, datasets or direct testimony. Record title, URL or file path, publication date, access date and the claims supported. Distinguish first-hand evidence from secondary synthesis.
3. Cross-check consequential claims with independent evidence. Note conflicts, methodological caveats, incentives and staleness. Avoid counting two syndicated articles as independent confirmation. Check quotes, arithmetic and dates against originals.
4. Write sections around findings and disputed questions. Mark observed facts, inferences, plausible alternatives and missing evidence. Cite each material claim near its supporting source with retrievable document/page/section references where available.
5. End with findings, confidence, limitations, unanswered questions and as-of date. Deliver a readable text report by default. Use document Skills for a requested DOCX/PDF only when generation and verification tools are available.

## Failure and safety
Never invent URLs, quotations, retrieved documents or statistics. Report inaccessible sources as unread rather than pretending to have consulted them. When web access is absent, work from user-supplied documents and disclose coverage gaps. Do not add external search services, a vector database, orchestration engine, paid API usage, external publication or account mutations.
